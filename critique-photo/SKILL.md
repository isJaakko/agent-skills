# 照片质量分析与提升

基于实际可见的照片，解释哪些拍摄选择有效、哪些因素影响表达，以及下一次如何拍得更好。默认用中文，以用户的经验和创作目的调整术语与深度。

## 获取足够的图像证据

- 先查看照片。对本地文件使用可用的图像查看工具；不能只读取文件名或元数据后就点评画面。未收到照片或无法读取时，请用户上传照片或提供可访问的本地文件，不编造分析。
- 未说明用途时，先按照片呈现的主体和风格点评，并将推测的创作意图明确写成假设。只有用途会显著改变结论时才追问，例如纪实留念与商业产品展示的取舍。
- 缩略图、聊天压缩图和截图足以分析大体构图与光线，但未必能判断精确对焦、微小噪点、锐化痕迹和可打印尺寸。只在这些限制影响结论时说明；需要时请求原图，同时继续完成已能支持的分析。
- 如果文件与工具允许，可按需查看原始分辨率、关键区域原尺寸细节和 EXIF。EXIF 仅作辅助证据，可能缺失或被修改；不要猜测具体设备、焦距、光圈、快门或 ISO，也不要为点评输出无关的 GPS 等信息。

## 从表达效果定位问题

先确定观众最先看到什么、主体是否明确，再选择真正影响照片的维度分析。无需逐项填满检查表。

| 维度 | 有用的判断依据 |
| --- | --- |
| 构图与背景 | 视觉中心、主体与背景分离、画面边缘干扰、遮挡或切割、空间关系、视线与运动方向、地平线和透视 |
| 用光与曝光 | 光线方向与软硬、主体明暗层次、面部或关键纹理可读性、高光与阴影是否仍有细节、逆光和混合光的效果 |
| 清晰度与技术质量 | 关键部位的可见清晰度、景深分配、拖影方向、噪点、压缩伪影、锐化光晕；在分辨率足够时才下细节结论 |
| 色彩与影调 | 白平衡一致性、色彩关系、局部色偏、饱和度、对比度与主体表达是否协调 |
| 时机与表达 | 姿态、表情、动作瞬间、叙事线索、情绪和画面元素是否支持创作目的 |

根据题材改变重点：人像关注关键眼部、面部光线和背景关系；风光关注层次、天气光线和前景作用；运动关注动作瞬间与模糊效果；产品关注形体、材质、反光控制和色彩准确性；街拍与纪实关注瞬间、信息关系与现场感。

不要把居中、暗调、颗粒、浅景深、倾斜或运动模糊自动视为缺陷。评价它们是否帮助表达；区分技术瑕疵与审美选择。人像建议讨论拍摄与呈现，不给人物外貌打分。

对关键问题使用这条推理链：

**可见现象与位置 → 对画面的影响 → 可能原因 → 可执行调整。**

观察与原因分开写。比如眼部不够清晰，并不能单凭缩略图认定为失焦；景深不足、主体移动、手抖、降噪和压缩都可能有关。证据不足时给出有依据的少量候选原因及确认办法，而不是罗列所有可能性。不能根据预览里看似纯白或纯黑的区域断言 RAW 已不可恢复。

## 将建议变成能执行的动作

优先处理对主体表达影响最大的少数问题，通常给出三项以内的主要改进；不要为凑数添加问题。明确哪些优点值得保留。

### 下次拍摄

建议写到动作层面：机位向哪侧移动、拍摄高度如何变化、何处裁切或留白、主体与背景如何拉开、如何调整光线方向、对焦落在哪里、何时按快门。描述预期效果，并指出相关取舍。

手机用户优先得到手机可执行的动作，例如点击主体对焦、调整曝光、换拍摄位置、利用窗边光、等待动作停顿；不要假定手机能调光圈。相机用户可得到对焦模式、快门、光圈和 ISO 的调整方向。具体参数只作为有场景前提的试拍起点，注明动作速度、焦距、光照和防抖会影响选择；不根据成片反推出精确拍摄参数。

### 当前照片的后期补救

区分可补救的构图、色偏与影调问题，以及通常难以完整恢复的严重失焦、拖影、缺失细节。提供裁切、白平衡、局部明暗、适度降噪或锐化等调整顺序与目标，而不是没有依据的一组固定滑块数值。

说明会影响选择的代价，例如提亮阴影可能显露噪点、强降噪可能损失纹理、透视校正与裁切会损失边缘内容。不要承诺锐化能恢复真实缺失细节。纪实场景中的移除物体、合成与生成式补全属于内容改变，应与普通影调调整区分。只有用户要求实际修图时才进入编辑流程；点评本身不修改原文件。

## 组织输出

除非用户明确要求其他形式，输出必须同时包含完整文字说明和带标注的照片。标注图是文字点评的补充，不能用图片、图例或“已标注”之类的简短确认替代原有文字分析。文字部分采用以下结构，可随用户要求调整：

1. **整体判断**：一句话说清最成功之处和最影响效果的问题，结合用途而非笼统说“很好看”。
2. **值得保留的优点**：列出有画面证据的优势。
3. **优先改进**：每项对应可见位置、影响和拍摄调整；对原因不确定时标明。
4. **当前照片怎么补救**：给出简洁的后期操作顺序；无法可靠判断恢复空间时说明依据不足。
5. **下次试拍**：给出一个有针对性的对照练习，一次改变一个主要变量，并说明比较什么。

### 照片标注图（必需）

- 在原照片的副本上标注主要改进点，不覆盖原文件。保留原始完整取景、场景内容、色彩和曝光；仅添加标注，不实际执行裁切、移除物体或后期修复。
- 文字中“优先改进”的编号与图中编号一一对应。用少量高对比的圈框、箭头、虚线和简短中文标签准确指向对应区域；裁切建议使用虚线表示边界，保留线外画面供比较。涉及重拍的建议明确标为“重拍建议”，不要通过移动或重绘主体伪装成原片。
- 标签优先放在留白处，避免遮挡主体、问题证据和其他标注；图内只写简短提示，完整原因、取舍与操作建议仍保留在正文。不为凑标注数量虚构缺陷；没有明确问题时可标出值得保留的区域或可选构图尝试，并注明其性质。
- 使用当前环境可用且符合图像编辑规则的工具制作标注图；如使用生成式图像编辑，明确要求保留原画面，并检查是否发生场景漂移。结果若改变了关键证据，应修正，不能将其作为忠实原片标注交付。
- 查看成品，确认文字可读、编号与正文一致、箭头定位准确、画面未被意外裁切或改变。回复中直接展示标注图；工具已内联展示时无需重复嵌入，但最终文字点评仍须完整。提供图片文件链接时使用实际生成的路径。
- 少量照片逐张点评时，为每张提供对应标注图并标明文件名或编号；大量选片时先明确本轮详评的照片范围，为详评照片提供标注图。
- 若未收到照片、无法读取图像或标注工具不可用，明确说明尚缺标注图及具体原因，交付当前可完成的文字分析；不能声称已完成双份输出，也不能静默省略图片。

少量照片逐张使用文件名或编号标识，避免混淆证据；选片时按共同用途比较并给出推荐及取舍。大量照片先给出整体筛选与代表性问题，不声称已逐张审阅未查看的照片。

默认不打分。用户要求时，说明评分基于当前预览与用途，采用带文字解释的粗粒度维度评分，标注无法判断的维度，不用小数制造精确感。没有照片时不评分，也不把审美评分当作客观测量。

交付前确认：每个主要结论都有可见依据，推测没有冒充事实，前三项建议能被用户实际执行，评价没有套用与创作目的无关的规则；完整文字点评和经检查的标注图均已交付，图文编号一致，原文件未被覆盖。
